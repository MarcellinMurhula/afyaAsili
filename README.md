# 🇫🇷 Version Française : Description de la Plateforme

## Vue d'ensemble & Mission Clinique
**AfyaAsili • Kivu Health** est une plateforme de santé digitale de pointe conçue spécifiquement pour le suivi, la gestion et l'éducation thérapeutique du **diabète** dans le contexte des systèmes de santé d'Afrique de l'Est et de la région du Grand Kivu (RDC, Rwanda, Burundi).

Dans de nombreuses régions rurales et semi-urbaines d'Afrique subsaharienne, la prise en charge du diabète est entravée par le coût des médicaments modernes, l'accès limité aux centres de consultation et une faible alphabétisation médicale. Parallèlement, les populations font un usage intensif de la **pharmacopée traditionnelle africaine** et de l'alimentation locale sans toujours connaître leur impact exact sur la glycémie ou leurs interactions avec les traitements conventionnels (insuline, metformine).

**Notre Mission :** Créer un pont scientifique et sécurisé entre la **diabétologie moderne** et la **pharmacopée traditionnelle validée**, en fournissant un assistant IA clinique capable de comprendre les langues locales, d'analyser visuellement les repas et plantes médicinales par caméra, et de fonctionner parfaitement en mode **hors-ligne (PWA)** dans les zones à faible connectivité.

---

## Fonctionnalités Clés & Innovation

### 1. 🤖 Moteur IA Clinique & Ethnobotanique (Multimodal)
* **Analyse Visuelle (Caméra & Photos en Direct) :** Prise de photo instantanée de plats locaux (ex: *Foufou de manioc/sorgho*, *Saka-Saka / Pondu*, *Gombo*, *Ndakala / petits poissons du lac Kivu*) ou de plantes médicinales (ex: *Moringa oleifera*, *Vernonia amygdalina / Ndolé*, *Prunus africana*, *Bissap / Hibiscus*). L'IA identifie la composition, estime la charge glycémique et évalue la sécurité de la préparation cuisinée.
* **Analyse Vocale Multi-langues :** Enregistrement de notes vocales par le patient. L'IA transcrit, analyse les symptômes ou les questions nutritionnelles et répond oralement en français ou dans les langues vernaculaires.
* **Évaluation des Risques & Conseils de Préparation :** Avertissement sur les risques de pics glycémiques (ex: surconsommation de farines raffinées ou de manioc non fermenté) et recommandations sur les techniques de cuisson traditionnelles pour réduire la toxicité (cuisson prolongée, ajout de fibres à feuilles vertes).

### 2. 🌍 Localisation Régionale & Multilinguisme
La plateforme est nativement multilingue et adaptée aux réalités socioculturelles d'Afrique centrale et de l'Est :
* **Français :** Langue officielle médicale et administrative.
* **Kiswahili :** Langue véhiculaire majeure de l'Afrique de l'Est et du Kivu.
* **Lingala :** Langue nationale largement parlée en RDC.
* **Mashi :** Langue autochtone du Sud-Kivu (région de Bukavu / Walungu), indispensable pour atteindre les populations rurales âgées.

### 3. 🚨 Protocoles d'Urgence Diabétique Adaptés au Terrain
Un module d'urgence accessible à tout instant fournit des instructions vitales étape par étape :
* **Crise d'Hypoglycémie (< 70 mg/dL) :** Guide de resucrage rapide avec les ressources locales (eau sucrée, miel pur, fruits locaux). **Règle d'or Kivu :** Alerte stricte interdisant la prise de plantes amères (Vernonia, Ndakala) à jeun en cas de vertiges.
* **Pic d'Hyperglycémie (> 250 mg/dL) :** Protocole d'hydratation intensive et d'élimination immédiate des farines à index glycémique élevé.

### 4. 🔌 Santé Connectée & PWA Hors-Ligne
* **Progressive Web App (PWA) :** Architecture "Offline-First" permettant le fonctionnement en brousse ou lors des coupures de réseau. Les données patient sont sauvegardées localement de manière sécurisée et synchronisées lors du retour de la connexion.
* **Simulateur et Synchronisation IoT :** Prise en charge de la saisie manuelle de glycémie et simulation de synchronisation Bluetooth avec les glucomètres intelligents.

## Accessibilité & Inclusion (UI/UX Inclusif)

Pour surmonter les barrières de la fracture numérique, des troubles de la vision (fréquents chez les patients diabétiques) et de l'analphabétisme, **AfyaAsili** propose une **double interface basculable à la volée** :

### 🟢 Mode Accessible & Simplifié (Patient)
* **Design Ergonomique "Grand Format" :** Suppression de la navigation complexe. Présentation de **3 indicateurs vitaux géants** (Dernière Glycémie, Pression Artérielle, Poids/IMC).
* **Code Couleur "Feu Tricolore" Universel :**
  * 🟢 **Normal :** Glycémie stable et équilibrée (80–130 mg/dL).
  * 🟠 **Vigilance :** Glycémie modérée ou à surveiller, conseils diététiques requis.
  * 🔴 **Urgence :** Valeur critique nécessitant une intervention médicale immédiate.
* **Synthèse Vocale Intégrée (TTS - Text-To-Speech) :** Chaque résultat, indicateur ou conseil peut être **lu à haute voix** par l'application dans la langue sélectionnée d'un simple clic sur le bouton haut-parleur.
* **4 Boutons d'Action Massifs :** Accès direct aux 4 actions clés : **Parler (Audio)**, **Prendre une Photo (Caméra)**, **Filmer une Vidéo (Cuisson)**, et **Écrire (Clavier)**.

### 📊 Mode Clinique & Détaillé (Médecin / Patient Éduqué)
* **Tableau de Bord Analytique :** Suivi graphique interactif de l'évolution de la glycémie dans le temps (courbes de tendances, moyennes hebdomadaires).
* **Journalisation Détaillée :** Enregistrement des repas, doses de traitement, activités physiques et observations cliniques.
* **Exportation des Données :** Génération de rapports médicaux pour les consultations hospitalières.

# 🇬🇧 English Version: Platform Description

## Overview & Clinical Mission
**AfyaAsili • Kivu Health** is a cutting-edge digital health platform specifically engineered for diabetes monitoring, therapeutic education, and clinical decision support in East Africa and the Greater Kivu region (DRC, Rwanda, Burundi).

In many rural and semi-urban areas of Sub-Saharan Africa, effective diabetes management is challenged by the high cost of modern pharmaceuticals, limited access to medical centers, and varying levels of health literacy. Concurrently, populations rely heavily on **traditional African pharmacopeia** and indigenous staple diets without precise guidance regarding their glycemic index or potential interactions with conventional medications (e.g., insulin, metformin).

**Our Mission:** To build a medically validated, culturally resonant bridge between **modern diabetology** and **scientific traditional herbal medicine**. We provide an AI-powered clinical assistant capable of understanding regional languages, analyzing meals and medicinal plants via live camera vision, and functioning seamlessly **offline as a PWA** in remote, low-connectivity healthcare environments.

---

## Key Features & Innovation

### 1. 🤖 Multimodal Ethnobotanical & Clinical AI Engine
* **Visual Camera Analysis (Live Photo & Video):** Instant image capture and analysis of traditional dishes (e.g., *Sorghum/Millet/Cassava Fufu*, *Saka-Saka / Pondu*, *Okra*, *Lake Kivu Ndakala fish*) and medicinal herbs (e.g., *Moringa oleifera*, *Vernonia amygdalina / Bitter Leaf*, *Prunus africana*, *Hibiscus / Bissap*). The AI evaluates glycemic load, ingredient composition, and cooking preparation safety.
* **Multilingual Voice Analysis:** Patients can record voice symptom logs or dietary queries in local dialects. The AI transcribes, analyzes clinical risk factors, and provides spoken audio responses.
* **Preparation Critiques & Toxicity Prevention:** Delivers real-time advice on how traditional food preparation (e.g., boiling techniques for cassava leaves, fermenting doughs) impacts blood glucose spikes and eliminates naturally occurring plant toxins.

### 2. 🌍 Deep Regional Localization
Designed from the ground up for Central and East African sociocultural realities:
* **French:** Official medical and administrative language.
* **Swahili (Kiswahili):** Major lingua franca across East Africa and the Kivu provinces.
* **Lingala:** National language widely spoken across the Democratic Republic of the Congo.
* **Mashi:** Indigenous language of South Kivu (Bukavu / Walungu territories), critical for engaging rural and elderly patient demographics.

### 3. 🚨 Field-Adapted Emergency Diabetic Protocols
An always-accessible emergency safety module providing instant, life-saving guidance:
* **Hypoglycemia Crisis (< 70 mg/dL):** Rapid blood sugar restoration protocol utilizing locally available resources (sugar water, pure honey, natural fruits). **The Kivu Golden Rule:** Explicit warnings against consuming bitter blood-sugar-lowering herbs (*Vernonia*, *Ndakala*) on an empty stomach during dizzy spells.
* **Hyperglycemia Spike (> 250 mg/dL):** Immediate hydration guidelines and instructions to halt refined carbohydrate intake.

### 4. 🔌 Offline-First PWA & Connected Health (IoT)
* **Progressive Web App (PWA):** Engineered with an offline-first cache architecture, ensuring uninterrupted usability in rural clinics or during cellular network blackouts. Patient records are locally persisted and automatically synced when connectivity is restored.
* **IoT & Glucometer Integration:** Supports manual blood glucose data entry as well as simulated Bluetooth syncing with smart glucose meters.

---

## Accessibility & Inclusion (Inclusive UI/UX)

To bridge the digital divide, accommodate visual impairments (common among diabetic patients), and support low-literacy users, **AfyaAsili** features a **dual-mode interface that switches instantly**:

### 🟢 Accessible & Simplified Mode (Patient)
* **Large-Format Ergonomic Design:** Replaces complex navigation menus with **3 massive visual indicators** (Latest Blood Glucose, Blood Pressure, Weight/BMI).
* **Universal Traffic-Light Feedback:**
  * 🟢 **Normal (Green):** Stable, balanced blood sugar (80–130 mg/dL).
  * 🟠 **Vigilance (Amber):** Moderate elevation or attention required; dietary adjustments suggested.
  * 🔴 **Emergency (Red):** Critical glucose level requiring immediate clinical intervention.
* **Integrated Text-To-Speech (TTS):** Every diagnosis, measurement, or piece of advice can be **read aloud in natural voice** in the user's chosen indigenous language with a single tap.
* **4 Massive Action Tiles:** Direct, icon-driven access to primary tools: **Speak (Audio)**, **Take Photo (Camera)**, **Record Video (Cooking)**, and **Write (Keyboard)**.

### 📊 Clinical & Detailed Mode (Physician / Educated Patient)
* **Analytical Medical Dashboard:** Interactive graphical tracking of longitudinal blood glucose trends, averages, and time-in-range metrics.
* **Comprehensive Clinical Logs:** Detailed tracking of dietary intake, medication dosing schedules, physical activity, and clinical notes.
* **Data Export:** Generate structured health reports for hospital consultations and medical follow-ups.

---

## Ethnobotanical & Nutritional Directory

The **Medicinal Plants & Traditional Accompaniments Directory** serves as an interactive, scientifically validated encyclopedia of East African flora:
* **Comprehensive Plant Monographs:** Detailed entries for *Moringa oleifera*, *Vernonia amygdalina (Bitter Leaf / Ndolé)*, *Prunus africana*, *Hibiscus sabdariffa*, *Zingiber officinale*, etc.
* **Traditional Staple Food Profiles:** *Saka-Saka (Pondu)*, *Cassava / Millet / Sorghum Fufu*, *Okra*, *Ndakala*.
* **Scientific & Clinical Metadata:** Glycemic Index (GI), estimated glycemic load, active phytochemicals (polyphenols, antioxidants), and **peer-reviewed clinical evidence** regarding insulin sensitivity enhancement.
* **Safety Protocols & Contraindications:** Clear warnings regarding preparation safety (e.g., boiling protocols to eliminate cyanogenic glycosides in cassava), maximum safe daily dosages, and herb-drug interactions (e.g., severe hypoglycemia risks when mixing insulin secretagogues with traditional herbs).

---

## Architecture & Technologies
* **Frontend Framework:** React 18, TypeScript, Vite.
* **Styling & UI:** Tailwind CSS utilizing a custom, high-contrast organic color palette (warm earth, forest green, terracotta, and soft stone neutral tones).
* **Iconography:** Lucide React.
* **Data Visualization:** Recharts / D3.js for clinical glucose curve charting.
* **Audio & Hardware APIs:** HTML5 Web Speech API (speech synthesis and recognition) and live MediaStream / Canvas APIs for real-time camera viewfinder inspection.
* **Cloud AI Connector:** Standardized AI gateway supporting Kaggle Models / Gemini API token integration for deep clinical inference.

# 🚀 Installation & Démarrage Rapide / Getting Started

### Prérequis / Prerequisites
* Node.js v18+ ou version ultérieure / Node.js v18 or later
* npm ou yarn / npm or yarn package manager

### 1. Cloner le dépôt / Clone the repository
```bash
git clone https://github.com/votre-compte/afya-asili-kivu-health.git
cd afya-asili-kivu-health
```

### 2. Installer les dépendances / Install dependencies
```bash
npm install
```

### 3. Configurer les variables d'environnement / Configure environment variables
Créez un fichier `.env.local` à la racine du projet (optionnel si vous utilisez le mode démo IA local ou le connecteur Kaggle dans l'interface) :
Create a `.env.local` file at the root of the project (optional if using the built-in local AI demo mode or the UI Kaggle API connector):
```env
# Clé API pour l'inférence IA Cloud (optionnel) / API Key for Cloud AI inference (optional)
VITE_GEMINI_API_KEY="votre_cle_api_ici"
```

### 4. Lancer le serveur de développement / Start the development server
```bash
npm run dev
```
Ouvrez votre navigateur sur / Open your browser at: `http://localhost:3000`

### 5. Construction pour la production / Build for production
Pour compiler l'application en mode PWA optimisé pour le déploiement sur Cloud Run ou un hébergement statique :
To compile the application as an optimized PWA for Cloud Run or static hosting:
```bash
npm run build
npm run preview
```
